# rocosmo

Research into a [Roc](https://www.roc-lang.org/) platform and toolchain for [Cosmopolitan / Actually Portable Executable](https://github.com/jart/cosmopolitan)-style application distribution, including builds originating on Apple Silicon, Linux, and Windows.

Status: research kickoff. No working Roc-to-APE platform or portability claim has been established yet.

See [INTENT.md](INTENT.md) for scope and evidence requirements, and [PLAN.md](PLAN.md) for the research sequence. The research agent will add a pinned Nix environment, experiments, and a feasibility report. Direct official upstream Cosmopolitan packages may be used instead of an outdated nixpkgs package.
